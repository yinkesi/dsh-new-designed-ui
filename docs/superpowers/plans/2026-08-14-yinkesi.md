# Yinkesi DeepSeek Harness UI Plugin Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build, verify, package, and install a removable `dsh-yinkesi` browser-only plugin that makes DeepSeek Harness `0.1.0-rc.5` look Claude-inspired, adds Apple-like interaction polish, uses the official blue whale mark, and preserves every Harness feature including the complete Trajectory view.

**Architecture:** Keep the official Harness source untouched. Ship one DSH profile bundle whose Host entry is an empty lifecycle function and whose prebuilt browser client applies official theme tokens, installs a scoped CSS layer, and runs a guarded `rc.5` DOM adapter. The adapter mirrors existing Conversation/Trajectory and Settings controls instead of moving or replacing React-owned nodes. Any layout mismatch falls back to token-only styling and leaves all official controls visible.

**Tech Stack:** Node.js 24, dependency-free JavaScript modules, Node's built-in test runner, DSH `0.1.0-rc.5` ModuleLoader bundle contract, official `ui-theme` client service, CSS custom properties, DOM `MutationObserver`, Playwright supplied by the local Harness workspace.
